# Security Policy

## Reporting vulnerabilities

Please do not disclose suspected vulnerabilities in public issues. Use GitHub's **Report a vulnerability** / private vulnerability reporting feature if enabled for this repository. If it is not available, contact the repository maintainer privately through their GitHub profile to arrange a secure reporting channel.

Include affected version, reproduction steps, impact, and any proposed mitigation. Do not include credentials or sensitive data in reports.

## Supported versions

Until the first tagged release, only the current `main` branch receives fixes. After releases begin, support will be documented here.
